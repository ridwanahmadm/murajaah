Aktivasi Google Drive untuk pengelola

Pengguna umum cukup mengikuti panduan cadangan dan pemulihan. Halaman ini untuk pengelola yang mengaktifkan koneksi Google pada situs.

  1. Buat/pilih proyek di Google Cloud Console. Gunakan proyek tanpa akun billing; jangan aktifkan layanan berbayar. Aktifkan Google Drive API.
  2. Di Google Auth Platform, atur nama aplikasi Murajaah, alamat dukungan dan audience External. Untuk uji awal, tambahkan akun Anda sebagai test user. Akun lain tidak bisa memakai aplikasi yang masih Testing kecuali ditambahkan. Ikuti persyaratan publikasi/verifikasi Google sebelum membuka akses untuk semua pengguna.
  3. Tambahkan scope https://www.googleapis.com/auth/drive.appdata saja untuk cadangan. Tidak diperlukan akses penuh seluruh Drive.
  4. Buat OAuth Client bertipe Web application. Tambahkan Authorized JavaScript Origins https://murajaah.ridwan-22693.chatgpt.site dan https://ridwanahmadm.github.io. Origin tidak memakai /murajaah/ atau #/pengaturan. Untuk lokal, tambahkan http://127.0.0.1:3000 bila dibutuhkan. Jangan gunakan origin wildcard.
  5. Salin Client ID yang berakhir .apps.googleusercontent.com. Jangan membagikan Client Secret atau kata sandi. Untuk uji browser ini, masukkan Client ID di Pengaturan → Konfigurasi Google Drive untuk pengelola.
  6. Untuk semua pengguna, pengelola menerbitkan ulang dengan variabel publik NEXT_PUBLIC_GOOGLE_CLIENT_ID. GitHub Pages membaca Repository Variable GOOGLE_CLIENT_ID. Client ID adalah identitas publik, bukan kredensial rahasia.
  7. Tetapkan kuota proyek sesuai batas gratis di Cloud Console dan periksa pemakaian. Integrasi hanya mengakses Drive saat pengguna menekan tombol; tanpa polling, retry otomatis, atau layanan inference berbayar. Jika izin/kuota tidak tersedia, gunakan ekspor JSON. Jangan mengaktifkan billing untuk mengatasi kegagalan kuota.

Akses token hanya disimpan di memori sesi, tidak di IndexedDB, localStorage atau cadangan. Google meminta pengguna memilih akun dan memberikan izin; masa aktif token terbatas. Memutuskan koneksi tidak menghapus cadangan.

Rujukan resmi: OAuth untuk browser, folder data aplikasi, dan kuota dan ketentuan biaya Drive API. Periksa ketentuan Google terbaru sebelum aktivasi; integrasi tidak menjanjikan kuota tanpa batas.
