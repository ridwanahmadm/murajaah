Cadangkan dan pulihkan data di HP

Murajaah menyimpan data belajar otomatis di browser perangkat Anda. Refresh tidak menghapus data tersimpan. Cadangan adalah salinan terpisah untuk memulihkan data setelah browser dibersihkan atau saat berganti HP.

1. Simpan cadangan ke memori HP

  1. Buka Pengaturan → Cadangan data.
  2. Tekan Ekspor JSON. Tunggu hingga muncul pesan “Cadangan diunduh”.
  3. Cari file murajaah-…json melalui aplikasi Files/File Manager, folder Unduhan/Downloads, atau daftar unduhan browser.
  4. Simpan salinan di tempat lain: unggah file tersebut melalui aplikasi Google Drive, atau pindahkan ke perangkat lain. Simpan cadangan terbaru setelah menambah materi atau catatan penting.

File mencakup isi materi, soal, catatan kajian, draf, jawaban kuis, dan progres. Kata sandi, kode akses AI, serta token Google tidak disertakan. Simpan PDF asli yang Anda unggah secara terpisah jika masih diperlukan.

2. Pulihkan dari file setelah data terhapus

  1. Buka Murajaah di browser/alamat situs yang ingin dipakai, lalu Pengaturan.
  2. Jika file disimpan di Drive biasa, unduh dahulu lewat aplikasi Google Drive ke HP.
  3. Pada Impor cadangan JSON, pilih file murajaah-…json. Maksimal 20 MB.
  4. Tinjau tanggal cadangan, jumlah materi, catatan, dan jawaban. File rusak atau tidak cocok akan ditolak tanpa mengganti data.
  5. Jika masih ada data baru pada HP, Ekspor JSON dahulu: impor mengganti seluruh data lokal, bukan menggabungkannya.
  6. Tekan Konfirmasi ganti data dan impor. Tunggu pesan “Cadangan berhasil diimpor”, lalu buka Materi atau Catatan.

3. Cadangan langsung ke Google Drive

Fitur ini memerlukan koneksi Google yang sudah diaktifkan pengelola. Internet diperlukan; penyimpanan lokal dan ekspor file tetap bisa digunakan tanpa Drive.

  1. Di Pengaturan, tekan Siapkan koneksi Google, lalu Hubungkan Google Drive.
  2. Pilih akun Anda dan izinkan akses folder cadangan khusus Murajaah.
  3. Tekan Simpan cadangan ke Drive setelah perubahan penting. Setiap tindakan membuat salinan baru; cadangan lama tetap tersedia.
  4. Untuk memulihkan, hubungkan akun Google yang sama, tekan Lihat cadangan Drive, pilih tanggal cadangan, lalu Tinjau pemulihan dari Drive.
  5. Periksa ringkasan dan tekan Konfirmasi ganti data dan impor. Anda dapat menekan Batalkan impor jika belum yakin.

Cadangan langsung tersimpan di folder aplikasi tersembunyi dan diakses lewat Murajaah; file yang diunggah manual ke Drive biasa tetap dipulihkan melalui Impor JSON. Koneksi Google dapat berakhir; hubungkan kembali jika diminta. Ini cadangan manual, bukan sinkronisasi langsung antarperangkat.

Jika belum pernah membuat cadangan

Data pribadi yang sudah dihapus dari browser tidak dapat dipulihkan oleh Murajaah tanpa file cadangan atau cadangan Drive yang pernah dibuat. Materi bawaan tersedia kembali, tetapi catatan dan progres pribadi tidak bisa dibuat ulang otomatis.

Hindari mode privat/incognito untuk belajar. Gunakan Pertahankan penyimpanan dan, bila tersedia, Pasang Murajaah/Tambahkan ke Layar Utama. Tetap buat cadangan, karena menghapus data browser atau aplikasi dapat menghapus data lokal.
