Cadangkan dan pulihkan data di HP

Murajaah menyimpan data belajar otomatis di browser perangkat Anda. Refresh tidak menghapus data tersimpan. Cadangan adalah salinan terpisah untuk memulihkan data setelah browser dibersihkan atau saat berganti HP.

1. Simpan cadangan ke memori HP

  1. Buka Pengaturan → Cadangan data.
  2. Tekan Ekspor JSON. Tunggu hingga muncul pesan “Cadangan diunduh”.
  3. Cari file murajaah-…json melalui aplikasi Files/File Manager, folder Unduhan/Downloads, atau daftar unduhan browser.
  4. Simpan salinan di tempat lain: salin ke media penyimpanan lain atau pindahkan ke perangkat lain. Simpan cadangan terbaru setelah menambah materi atau catatan penting.

File mencakup isi materi, soal, catatan kajian beserta foldernya, draf, jawaban kuis, dan progres. Kata sandi dan kode akses AI tidak disertakan. Simpan PDF asli yang Anda unggah secara terpisah jika masih diperlukan.

2. Pulihkan dari file setelah data terhapus

  1. Buka Murajaah di browser/alamat situs yang ingin dipakai, lalu Pengaturan.
  2. Pastikan file cadangan sudah tersedia di Files/File Manager atau folder Unduhan HP.
  3. Pada Impor cadangan JSON, pilih file murajaah-…json. Maksimal 20 MB.
  4. Tinjau tanggal cadangan, jumlah materi, catatan, dan jawaban. File rusak atau tidak cocok akan ditolak tanpa mengganti data.
  5. Jika masih ada data baru pada HP, Ekspor JSON dahulu: impor mengganti seluruh data lokal, bukan menggabungkannya.
  6. Tekan Konfirmasi ganti data dan impor. Tunggu pesan “Cadangan berhasil diimpor”, lalu buka Materi atau Catatan.

Jika belum pernah membuat cadangan

Data pribadi yang sudah dihapus dari browser tidak dapat dipulihkan oleh Murajaah tanpa file cadangan yang pernah dibuat. Materi bawaan tersedia kembali, tetapi catatan dan progres pribadi tidak bisa dibuat ulang otomatis.

Hindari mode privat/incognito untuk belajar. Gunakan Pertahankan penyimpanan dan, bila tersedia, Pasang Murajaah/Tambahkan ke Layar Utama. Tetap buat cadangan, karena menghapus data browser atau aplikasi dapat menghapus data lokal.
